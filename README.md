# Wingscraft — 第7版

展開して index.html をブラウザで開いてください。ファイルを直接開く場合、一部のブラウザではコピー機能が使えません。通常の公開環境での利用を想定しています。

## 第6版の仕上げ

- トップを7セクションから5セクションへ整理。進め方はサービスのFAQへ、製品情報は専用ページへ集約。
- スタジオ紹介で重複する理念を削減。トップの説明文と相談への呼びかけを短く編集。
- 登場時のフェード、スクロールに応じたヘッダー、カード・ボタン・予約選択・FAQ・入力欄への反応を調整。
- 動きを減らす端末設定に追従。キーボードで移動した要素は隠さず表示し、独自スクロール制御や無限アニメーションは使用しません。
- 8ページ × 2言語 × 320/768/1440pxの48パターンで横はみ出しと見出し超過がないことを確認。390pxでもトップを目視確認。
- デモ完了、FAQ開閉、問い合わせ種別の引き継ぎ、コンソールの警告・エラーなしを確認。7つのJS構文と、動きを減らす設定の変更時の動作を検証。

情報量の判断は内容の重複と画面構成の点検に基づきます。実際の訪問者による利用テストやアクセス解析はまだ行っていません。

## 引き継いだ機能

- 日英の見出しを意味のまとまりで折り返すよう調整。本文の不要な固定改行を除去し、画面幅に合わせて配置。
- 箇条書きの「＋」を小さな点に変更。開閉するFAQは矢印で表現。
- 制作例ページと、架空のコーヒースタンド Sumi Coffee の操作可能な自主制作を追加。実際の納品実績ではありません。
- サービス別の相談ボタンから、フォームの相談種別を選択済みで表示。制作例からは参考例名も引き継ぎます。
- Formspree接続用の送信処理、送信中・受付成功・失敗・結果不明・制限時の案内を実装。失敗時は入力を保持し、送信中の重複操作を防ぎます。
- 迷惑送信向けの隠しフィールド、文字数・必須・メール形式の検証を追加。送信サービス側の対策も公開時に設定してください。
- ロゴ・favicon・ホーム画面アイコン・共有画像を同一の文字パスから生成。端末の書体差に依存しません。
- 情報の取り扱いページ、公開設定を一か所から反映する手順を追加。

## 現在の状態と、残っている設定

公開URL・ホスティング・送信サービスは未定です。サイト内の直接送信はまだ有効ではなく、現在はメールソフトへ内容を渡す方式で動作します。送信完了とは表示しません。

受信先は wingscraft.studio@gmail.com。Gmailアドレス自体はサイト用の送信エンドポイントにはなりません。送信サービスのフォームを作成し、受信先メールの認証を済ませて接続する必要があります。

サイト内送信の接続先としてFormspreeに対応するコードを用意しています。別のサービスを選ぶ場合は、接続処理の変更が必要です。登録・契約・本番への送信は行っていません。

## 接続・公開する手順

1. 公開先URLを決めます。
2. Formspreeを使う場合はフォームを作成し、受信先を wingscraft.studio@gmail.com に設定・認証します。管理画面で迷惑送信対策・許可ドメイン・利用上限を確認してください。
3. site-settings.json の publicURL に実際の公開URL、formspreeEndpoint に公開用フォームURL（https://formspree.io/f/ で始まるURL）を入力します。APIキーやGmailのパスワードは入力しないでください。
4. このフォルダーで python3 tools/configure.py を実行します。ブラウザ用設定、canonical、og:url、共有画像の絶対URL、robots.txt、sitemap.xmlを生成します。公開URLが空なら架空のURLは生成しません。
5. フォルダー内のサイト用ファイルを静的ホスティングへ配置します。README.md・tools・site-settings.jsonは運用資料で、公開に必須ではありません。_headersは対応するホスティングでのみ使われます。
6. 本番URLで入力から送信・Gmailへの到着・返信先を確認します。SNSの共有表示、iPhone・Android実機でも最終確認してください。

設定値はsite-settings.jsonを正本にしてください。公開用フォームURLは秘密鍵ではありません。設定を変えてスクリプトを実行すると、設定ファイルの読み込みURLも更新されます。

公式資料：
- FormspreeのJavaScript送信 https://help.formspree.io/articles/building-your-form/submit-forms-with-javascript-ajax/
- 迷惑送信向けの隠しフィールド https://help.formspree.io/articles/building-your-form/honeypot-spam-filtering/

## 表示言語

初回はブラウザの最優先言語が日本語なら日本語、それ以外は英語です。手動切替だけを端末に保存して次回も優先します。日本語が第二候補以降なら英語です。地域やIPアドレスでは判定しません。

言語の初期化はCSSより前に実行します。JavaScript無効時はHTMLの日本語表示になります。SNS・検索のクローラーがJavaScriptを実行しない場合も初期の日本語を読みます。英語の独立URLはありません。

## 情報の扱い

フォーム入力の自動保存は行いません。手動で選択した表示言語だけを端末に保存します。未接続時、入力内容はサイトへ送信されず、ユーザー自身のメールソフトから送信します。Formspree接続後は同サービスを経由し、送信内容が処理・保管されます。情報の取り扱いページは有効な送信方式を表示します。

## 確認結果と限界

- 8ページ・日本語と英語を1440px、768px、390px、320pxで点検。横のはみ出し・見出しの領域超過なし。
- スマートフォン幅で主見出しの実際の行分割を確認。制作例の日本語見出しはPCでも句の途中で切れないよう修正。
- 制作例のメニューフィルター、サービス・参考例のフォームへの引き継ぎ、入力保持を確認。
- 送信処理を5種類の応答でテスト。本番送信は行っていません。ローカルの模擬画面で送信中・成功・失敗・失敗後の言語切替を確認。
- JS構文、全ローカルリンク、ページ間アンカー、素材、見出し、ID重複を検証。
- 仮の設定を置いたテスト用コピーで公開メタデータ生成と設定リセットを検証。納品用には仮の公開URLを設定していません。

画面幅を変えたブラウザ確認であり、iPhone・Android実機試験ではありません。実メールの到着・送信サービス側の迷惑送信対策・公開後の共有プレビューは未確認です。
